Features that actually exist — no mockups

Every card below is a real capability in the platform. No fake dashboards.

Digital Menu

Categories, items, prices, images, availability flag and popular badge. Reorder via position, hide sold-out instantly.

QR Code Menu

One link per restaurant (/restaurant/your-slug) + printable QR from dashboard. No app install, instant open.

Online Ordering

Customer adds to cart on phone, picks pickup or delivery, enters name & WhatsApp, submits. Server computes totals.

WhatsApp Ordering

Two flows: order via website (organized) or order via WhatsApp (pre-filled wa.me message with cart). You choose.

Restaurant Dashboard

Manage categories & items with image upload (WebP, compressed), edit availability, popular, price, position.

Order Management

Status flow: pending → confirmed → preparing → ready → out_for_delivery → completed / cancelled. Archive keeps revenue history.

Table Bookings

Customers book tables with date/time and count. You confirm or cancel, optionally via WhatsApp template message.

Analytics & QR

Dashboard KPIs: orders today, pending, revenue, plus analytics by hour/day and top items. QR generator and share link.
